# Web app is a non-agentic dashboard

Status: accepted. Narrows ADR-0002. Dashboard UI is not in the first slice.

Members talk only on Telegram. The public site is get-started: explain the product and open the bot. A later dashboard may show **career profile** and **opportunities** (including `pursuing`) without a composer and without the **conversation** transcript. History lives in Telegram.

When that dashboard is built, its lock is the Telegram Login Widget — dashboard-only, never a gate to talking. Bot magic links were rejected.

The canonical **conversation** still exists so Telegram messages and **digests** share one timeline.
