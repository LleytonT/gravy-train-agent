# Web app is a non-agentic dashboard

Status: accepted. Narrows ADR-0002.

Members talk only on Telegram. The web app shows the **career profile**, **opportunities**, and related records without a chat composer — Poke’s split: the agent is a contact; the site is a reading room.

The canonical **conversation** still exists so Telegram messages and **digests** share one timeline. The web may display that timeline later; it must not be a talk **surface**.
